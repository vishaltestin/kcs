# Bundled showreel

`corporate-gifting-reel.mp4` (8.6 s, 1920×1080, no audio, 3.4 MB) is the default
film the home page plays in the showreel band, and `public/images/video-poster.jpg`
is its poster frame.

| | |
| --- | --- |
| Source | Pexels — <https://www.pexels.com/video/a-business-person-preparing-a-package-7308090/> |
| Author | RDNE Stock project |
| Licence | [Pexels License](https://www.pexels.com/license/) — free for commercial use, no attribution required, no resale of the clip itself |
| Modifications | cropped/scaled poster frame; audio track removed; re-encoded (CRF 24, faststart) for smaller transfer |

Replace it any time from **Admin → Home bands → Showreel band**: paste a
YouTube/Vimeo link (recommended — nothing is stored here and it streams from
them) or upload your own MP4/WebM. The field sits empty only if you never save
that band, in which case this file plays.
